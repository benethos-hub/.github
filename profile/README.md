# benethos-hub

Open-source projects in AI, agents and software architecture. The tools here connect AI clients to real systems such as mailboxes, accounting software and market data. They are built for production use, with clear permissions and predictable behaviour.

## Projects

| Project | Description |
| --- | --- |
| [mailbox](https://github.com/benethos-hub/mailbox) | Self-hosted REST API and web UI for IMAP, JMAP, POP3, Microsoft 365 and Outlook.com mailboxes. Includes a Python client and an MCP server, so AI agents can read, sort, draft and send mail within the folders, rights and send limits you grant. |
| [lexware-office-mcp](https://github.com/benethos-hub/lexware-office-mcp) | Unofficial MCP server for the Lexware Office accounting API. Gives AI clients access to contacts, vouchers and invoices. No tool is active until you enable it. |
| [yahoo-finance-mcp](https://github.com/benethos-hub/yahoo-finance-mcp) | Unofficial MCP server for Yahoo Finance data via yfinance. Read-only, with prices, key figures, analyst estimates and stock screening. |
