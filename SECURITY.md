# Security

This policy applies to every repository of benethos-hub that has no security policy of its own. Reports of weaknesses are welcome.

## Reporting a vulnerability

Please do **not** open a public issue. Report it privately through GitHub on the repository concerned, under **Security → Report a vulnerability**.

Helpful in a report:

- what an attacker can reach or do, and from where
- the steps or a request that shows it, and the version or commit
- no real credentials, tokens or personal data: redact them

Please give time for a fix before publishing details. The advisory can name you, if you like.

## Versions

Fixes go into the latest release and `main` only. Older versions do not get them, so the newest release is the one to run.
